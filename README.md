# 3D図形ラボ

正多面体、曲面、フラードームをブラウザ上で生成し、360度回転して観察できる静的Webアプリです。GitHub Pagesでそのまま公開できます。

## 収録図形

- 正四面体、立方体、正八面体、正十二面体、正二十面体
- 球、トーラス、円錐、円柱
- ジオデシック球、フラードーム

## 操作

- 左ドラッグ／1本指：回転
- ホイール／ピンチ：拡大縮小
- 右ドラッグ／2本指：平行移動
- 右端または下端の操作バー：図形選択、自動回転、全体表示、視点、設定、集中表示

## 公開方法

1. GitHubに公開リポジトリを作成します。
2. このフォルダの内容をリポジトリ直下へ置き、`main`ブランチへ反映します。
3. 同梱のGitHub ActionsがGitHub Pagesへ公開します。
4. リポジトリの「Settings → Pages」で、必要に応じてSourceを「GitHub Actions」にします。

公開URLは通常 `https://ユーザー名.github.io/リポジトリ名/` です。初回の反映には数分かかる場合があります。

## 技術条件

- Three.js 0.180.0をCDNから読み込むため、閲覧時にインターネット接続が必要です。
- WebGL対応の新しいブラウザを使用してください。
- ビルド処理やサーバーは不要です。

## 図形を追加する場所

`index.html`内の次の3か所を更新します。

1. `shapeSelect`へ選択肢を追加
2. `names`と`hints`へ名称と説明を追加
3. `geometryFor()`へThree.jsの形状生成処理を追加

## 検証

HTML内のJavaScript構文と要素IDの対応を確認しています。実機ブラウザで、PC・スマートフォンの回転、ズーム、パネル操作、全画面を確認してください。
